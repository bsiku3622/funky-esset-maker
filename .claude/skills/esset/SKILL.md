# Funky Esset Maker 프로젝트 만들기

이 앱은 텍스트를 슬라이드·논문에 붙일 이미지로 바꿉니다. 여기서 할 수 있는 실질적인 일은
**프로젝트 JSON을 써 주는 것**입니다 — 사용자가 그 파일을 열면 알맞은 도구가 내용까지 채워진
채로 뜹니다.

## 절차

1. 무엇을 만들지 정합니다 (아래 도구 표).
2. `public/llms.txt`를 읽습니다 — 도구별 `data` 스키마·입력 문법·예시가 전부 거기 있습니다.
   **스키마를 기억에서 쓰지 말고 그 파일을 확인하세요.** 필드 이름이 틀리면 조용히 기본값으로
   대체되어, 열리긴 하는데 의도와 다른 결과가 나옵니다.
3. JSON을 사용자에게 전달할 위치(보통 `~/Downloads/`)에 쓰고 SendUserFile로 함께 보냅니다.
4. 여는 방법을 한 줄로 알려줍니다: 앱 사이드바 **열기**(⌘O) 또는 창에 드래그.

저장소 밖에서 작업 중이라 `llms.txt`가 없으면
`https://funky-esset-maker.vercel.app/llms.txt`를 가져오면 됩니다.

## 봉투

```json
{ "app": "funky-esset-maker", "format": 1, "tool": "<도구 id>", "data": { } }
```

`data`에 없는 필드는 기본값으로 채워지므로 **확신하는 것만** 넣습니다.

## 도구 고르기

| `tool` | 쓸 때 |
| --- | --- |
| `highlighter` | 코드 조각 |
| `latex` | 수식 하나, 또는 수식 섞인 본문 |
| `tabler` | 표 |
| `dsviz` | 리스트·딕셔너리 상태 (알고리즘 설명) |
| `grapher` | 자유로운 박스-화살표 다이어그램 |
| `aifig` | 논문에 들어갈 모델 구조도 |
| `cartesian` | 함수·극좌표·음함수 그래프 |
| `chart` | 막대·선·원·산점도 |
| `numline` | 수직선, 구간, 부등식 |
| `truth` | 진리표 |

`grapher`와 `aifig`가 헷갈리면: 논문 figure면 `aifig`(벡터 SVG·LaTeX 라벨·단 폭 프리셋),
슬라이드용 순서도면 `grapher`.

## 판단이 필요한 곳

- **표준 아키텍처(Transformer·ViT·U-Net·GAN·diffusion 등)는 JSON을 짜지 마세요.**
  AI Figure Maker에 템플릿 16종이 있고, 손으로 좌표를 찍는 것보다 배치가 훨씬 낫습니다.
  "템플릿에서 고르고 라벨만 고치세요"라고 안내합니다.
- 출판물이면 `aifig`의 `paletteId`를 `okabe` 또는 `tol`로 — 색각 이상에서도 구분됩니다.
- 배경은 기본이 투명입니다. 슬라이드에 그대로 얹히므로 대개 그대로 두면 됩니다.
- 여는 순간 그 도구에 있던 작업을 덮어씁니다. 사용자가 뭔가 작업 중이었을 것 같으면 미리
  한마디 합니다.
- 좌표를 직접 넣는 도구(`grapher`·`aifig`)는 겹치기 쉽습니다. 세로로 쌓을 땐 160px 정도,
  가로는 박스 폭 + 60px 정도 띄웁니다.

## 만든 뒤

PNG는 ⌘E 저장 / ⌘⇧C 복사. AI Figure Maker는 벡터 SVG와 TikZ도 나옵니다.
